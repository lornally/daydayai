| **F12** | **跳转到定义** / 浏览器 DevTools | 看源码和浏览器调试的入口                         |
| **F1**  | 帮助/文档                        | 查 API 文档或 IDE 帮助                           |

其中 **F2（重命名）、F9（断点）、F10/F11（单步调试）、F12（跳转定义）** 是除 F5 外使用频率最高的。如果只能记住一个，F12 跳转定义几乎每天都会用到。
