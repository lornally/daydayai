## 关键发现

### 1. 操作力高度集中
除了云豹（45gf）和 Navy（60g+），**知夏/知秋/碎碎冰/午夜翡翠/极地狐的操作力都在 50gf 左右**。差异主要体现在段落峰值和弹簧结构上，不是触发压力。

### 2. 云豹轴的真相
- **起始力 37gf** 确实最轻（手指轻轻一放就开始动）
- 但**操作力还是 45gf**，和 BOX 白轴 V2 同级
- 真正卖点是**"CLICK 声最大"**

### 3. 午夜翡翠轴的真相
- 触发压力和知夏一样（50gf），**不算重**
- 但**段落峰值 85gf**，是凯华 Clicky 家族里最高的，段落感极其顶手
- 它是"**最强段落感**"，不是"最重压力"

### 4. 知秋轴的双段弹簧
- 操作力 50gf，触感力 55gf — 和云豹同级
- 双段弹簧让段落曲线更陡峭，手感"啪一下"更干脆

### 5. 碎碎冰轴的全 POM
- 操作力 50gf，触感力 60gf — 标准压力
- 卖点确实是全 POM 自润滑，顺滑+清脆的稀有组合

```
云豹 55gf ≈ 知秋 55gf < 碎碎冰 60gf ≈ 知夏/极地狐 ~60gf < 午夜翡翠 85gf

起始力（初始压力）排序：
云豹 37gf < 知冬 40gf < 其他 ~45-50gf
```
