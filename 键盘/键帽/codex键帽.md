## Drop MT3 3277 怎么买

目标不同，买法不一样：

1. **只想买 MT3，能接受有刻 QWERTY**
   - 打开 Drop 页面： https://drop.com/buy/drop-matt3o-mt3-3277-custom-keycap-set
   - 在 `Keycap Kit` 里选 `Base Kit`
   - 如果按钮是 `Add to cart` / `Ready to Ship`，就能买；如果是 `Request` / `Sold out`，就没现货

2. **想买 MT3 + Dvorak 有刻**
   - 直接打开 3277 Dvorak 补充包入口： https://drop.com/buy/drop-matt3o-mt3-3277-custom-keycap-set?defaultSelectionIds=966990
   - opencli/Google 搜索结果摘要写明：这里是给 Colemak、Colemak Mod DH、Dvorak、Programmer's Dvorak、Norman、Workman 准备的键帽
   - 这仍然只是补充包，不是完整键帽套
   - 如果要完整键盘有刻，需要同时买 3277 Base Kit + 这个 Dvorak/Colemak 补充包

3. **想买 MT3 + 无刻**
   - 只买 3277 Base Kit 不满足，因为它是有刻
   - 需要页面里有 `Blank` / `Blanks` Kit 才满足无刻
   - 本次没确认到 3277 无刻整套稳定现货

4. **Corsair 页面怎么看**
   - Corsair 的 3277 Base Kit 页面当前显示 `Sold out`，价格 $120
   - Corsair 的 /dev/tty Colemak/Dvorak 补充包页面当前也显示 `Sold out`，价格 $30
   - 3277 的 Dvorak 补充包优先看 Drop 的 `defaultSelectionIds=966990` 链接；Corsair 页面目前没有搜到对应 3277 Dvorak 单品
