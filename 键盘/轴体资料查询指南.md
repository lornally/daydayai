# 轴体资料查询指南

> 给 AI 助手的参考：如何查到准确的机械键盘轴体参数。

## 核心原则

**不要凭记忆回答轴体参数。** 轴体型号多、参数容易混淆，必须查证后再给出数据。如果无法上网，请明确告知用户"我无法验证这个数据"，不要编造。

---

## 可靠数据源（按优先级排序）

### 1. 官方产品页（最权威）

| 品牌 | 官网 | 说明 |
|------|------|------|
| 凯华 Kailh | kailh.net / kailhswitch.net | 两个站都是官方，参数最准 |
| TTC | 无独立英文官网 | 需要从经销商页面获取 |
| 佳达隆 Gateron | gateron.com / gateron.co | .com 是消费者站，.co 是 B2B 站 |
| Cherry | cherry.de | 德国官网，参数齐全 |

**查什么**：Operating Force、Tactile Force、Pre-travel、Total Travel、Return Force、Lifespan

| rtings | rtings.com/keyboard-switch | 有实测力度曲线图 |
| milktooth | milktooth.com | 两两对比，音色描述详细 |

### 3. 评测/声音测试站

### 常见参数术语对照

| 中文 | 英文 | 说明 |
|------|------|------|
| 操作力 | Operating Force / Actuation Force | 触发开关所需的力 |
| 触感力 | Tactile Force / Peak Force | 段落峰值力度 |
| 触底力 | Bottom-out Force | 按到底的力度 |
| 预行程 | Pre-travel / Actuation Travel | 从按下到触发的距离 |
| 总行程 | Total Travel | 从顶到底的总距离 |
| 回弹力 | Return Force | 弹簧回弹的最小力 |

## 常见错误和陷阱

1. **BOX Navy 不是 60g** — 实际操作力 75gf，触感力 95gf。很多旧文章标注错误。
2. **TTC 冰静轴V2 不是 35g** — 实际操作力 39gf，触底力 43gf。
3. **TTC 快银预行程不是 1.2mm** — 实际是 1.08mm。
4. **极地狐是 BOX 结构** — 虽然预行程 1.7mm 和标准 BOX 的 1.8mm 不同，但它属于 Kailh BOX Master V2 系列。
5. **"触发压力"含义模糊** — 不同厂商可能指操作力或触底力，需要看具体语境。优先使用 Operating Force。
6. **V1 和 V2 参数可能不同** — 同名轴体不同版本参数会变，注意区分版本。

## 验证流程

拿到一个轴体参数后：

1. 先查官方产品页确认
2. 如果官方没有，查 keeb-finder 或 rtings 的结构化数据
3. 如果还找不到，查 2-3 个经销商页面交叉验证
4. 如果数据源之间有冲突，以官方 > 专业测评站 > 经销商的优先级为准
5. 无法确认的数据标注 `~`（约等于），明确告知用户这是估算值
