**键帽怎么卖：**

| 售卖方式 | 常见数量 | 说明 |
| -------- | -------- | ---- |
| 基础套 / Base Kit | 104 / 108 / 117 / 129 / 139 / 150+ | 最常见，不一定只按 104 卖。键越多，越容易覆盖 75%、98、Alice、Mac 等特殊配列 |
| 增补包 / Extension Kit | 若干 | 补 7u 空格、短 Shift、ISO 回车、Mac 键等特殊尺寸 |
| 个性包 / Novelty Kit | 若干 | 图案键、装饰键，通常不是刚需 |
| 空格包 / Spacebar Kit | 若干 | 各种长度空格，比如 2u、2.25u、2.75u、6.25u、7u |
| 单颗 / 手作键帽 | 1 颗 | 多用于 ESC、方向键、装饰位 |

买的时候看“兼容性”比看“104 键”更重要。普通 87 键、104/108 全尺寸通常基础套就够；75%、98、Alice、HHKB、Mac 配列要看有没有对应增补键。无刻键帽不用管字符位置；如果用 Dvorak，有刻 Cherry/OEM 键帽不能随便换字母位置，因为每行高度不同。

你的偏好：要顶面面积大，还要有一点凹陷定位。XDA 虽然顶面最大，但太平，先排除；OSA 顶面偏小，排除；SA / MT3 更高、更深、更锁手指，也不优先。剩下优先看 MDA / ASA / KAT / Cherry / OEM。

**生产工艺（字符怎么印上去的）：**

| 工艺 | 原理 | 耐用度 |
|------|------|--------|
| **二色成型** (Double-shot) | 两层塑料注塑，字符本身是另一块塑料 | 字符基本不会磨掉，顶级 |
| **热升华** (Dye-sub) | 高温把油墨"渗"进 PBT 塑料内部 | 非常耐磨，PBT 常用 |
| **镭雕/激光** (Laser) | 激光烧掉表面，露出底色或烧焦 | 一般，久了可能变浅 |
| **喷油+镭雕** | 喷层漆再刻字，喷漆会掉 | 最差，便宜键盘常用 |

> 无刻字键帽没有这些问题，因为没有字符。

**其他常见术语：**

| 术语 | 意思 |
|------|------|
| **ANSI** | 美国标准配列，回车是横向长条形；你的 Q3/Q6 是这个大类 |
| **ISO** | 欧洲标准，回车是倒 7 字形，左 Shift 也短一截 |
| **1u / 2u / 6.25u** | 键帽宽度单位，1u = 一个标准字母键宽度。空格通常是 6.25u |
| **104键 / 108键 / 87键** | 104/108 = 全尺寸（含数字键盘，Q6 属于这一类但具体键数看版本）；87 = TKL（无数字区，你的 Q3）|
| **增补键 (Extra/Mod kit)** | 额外的小包键帽，包含非标准尺寸（如 7u 空格、ISO 回车）|
| **打油** | ABS 材质长期使用后表面被磨光滑、发亮的丑态 |
| **GMK** | 德国键帽厂商，最有名的是 Cherry 高度二色 ABS 键帽；贵主要贵在设计、授权、做工、品牌和收藏属性 |
