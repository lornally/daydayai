**键帽怎么卖：**

| 售卖方式 | 常见数量 | 说明 |
| -------- | -------- | ---- |
| 基础套 / Base Kit | 104 / 108 / 117 / 129 / 139 / 150+ | 最常见，不一定只按 104 卖。键越多，越容易覆盖 75%、98、Alice、Mac 等特殊配列 |
| 增补包 / Extension Kit | 若干 | 补 7u 空格、短 Shift、ISO 回车、Mac 键等特殊尺寸 |
| 个性包 / Novelty Kit | 若干 | 图案键、装饰键，通常不是刚需 |
| 空格包 / Spacebar Kit | 若干 | 各种长度空格，比如 2u、2.25u、2.75u、6.25u、7u |
| 单颗 / 手作键帽 | 1 颗 | 多用于 ESC、方向键、装饰位 |

买的时候看“兼容性”比看“104 键”更重要。普通 87 键、104/108 全尺寸通常基础套就够；75%、98、Alice、HHKB、Mac 配列要看有没有对应增补键。无刻键帽不用管字符位置；如果用 Dvorak，有刻 Cherry/OEM 键帽不能随便换字母位置，因为每行高度不同。

你的偏好：要顶面面积大，还要有一点凹陷定位。XDA 虽然顶面最大，但太平，先排除；OSA 顶面偏小，排除；SA / MT3 更高、更深、更锁手指，也不优先。剩下优先看 MDA / ASA / KAT / Cherry / OEM。

**高度（Profile）：**

Profile 指的是键帽的截面形状——高度、顶面倾斜角度、是否每行不同。

| Profile | 高度         | 类型   | 顶面形状 | 1u 顶面约尺寸 | 顶面约面积 | 凹陷深度约值 | 特点                                           |
| ------- | ------------ | ------ | -------- | -------------- | ---------- | ------------ | ---------------------------------------------- |
| DSA     | ≈7.6mm       | 统一型 | 球面     | 11.5×11.5mm    | ≈132mm²    | 0.8-1.2mm    | 每颗键帽一样高，球面顶，最矮，任意换位置不违和 |
| XDA     | ≈9.1mm       | 统一型 | 平面     | 13.5×13.5mm    | ≈182mm²    | 0-0.4mm      | 每颗键帽一样高，平面顶，比 DSA 稍宽稍大        |
| Cherry  | ≈8.4–11.9mm  | 阶梯型 | 圆柱形   | 12×13mm        | ≈156mm²    | 0.4-0.8mm    | 比 OEM 矮一点、行间角度更平缓，GMK 用的就是这个 |
| OEM     | ≈10.3–13.3mm | 阶梯型 | 圆柱形   | 12×13mm        | ≈156mm²    | 0.5-0.9mm    | 最常见的出厂键帽，每行高度/角度不同，中等高度  |
| OSA     | 接近 OEM     | 阶梯型 | 球面     | 11.5×12mm      | ≈138mm²    | 0.8-1.3mm    | Keychron 自家高度，OEM 高度 + SA 球面；你的 Q3/Q6 原厂就是这个 |
| MDA     | ≈9.5–12.5mm  | 阶梯型 | 球面     | 13×13mm        | ≈169mm²    | 0.5-1.0mm    | 顶面比较大，同时有轻微凹陷；比 XDA 更有定位感 |
| ASA     | ≈11–13mm     | 阶梯型 | 球面     | 12.5×13mm      | ≈163mm²    | 0.6-1.1mm    | AKKO 自有高度，类似更矮更宽松的 SA，顶面比 OSA/SA 大 |
| **KAT** | ≈11–14mm     | 阶梯型 | 球面     | 12×13mm        | ≈156mm²    | 0.8-1.3mm    | 中等高度，Cherry 和 SA 之间，兼顾球面手感      |
| **MT3** | ≈12.5–16.5mm | 阶梯型 | 球面     | 10.5×11.5mm    | ≈121mm²    | 1.5-2.5mm    | Matt3o 设计，高球帽，比 SA 略矮，极客味        |
| SA      | ≈14.2–17.3mm | 阶梯型 | 球面     | 11×12mm        | ≈132mm²    | 0.8-1.5mm    | 最高，球面顶，复古打字机风格                   |

- 顶面尺寸和凹陷深度没有统一行业标准，上表按常见 1u 字母键估算；不同厂家、不同模具会有明显差异。
- 按上表约值看，顶面面积排序大致是：XDA > MDA > ASA > Cherry / OEM / KAT > OSA / DSA / SA > MT3。Cherry / OEM 不是“小顶面”，只是比 XDA / MDA / ASA 小。
- **球面**（DSA / OSA / MDA / ASA / KAT / MT3 / SA）：顶面四边都往下弯，像碗底，手指接触面积通常更小，复古味浓
- **OSA**：Keychron 常用原厂键帽高度，名字可以理解成 OEM 高度 + SA 球面；比 SA 矮，比普通 OEM 更有复古球帽感
- **ASA**：AKKO 自有高度，可以理解成更矮、更宽松、更现代的 SA；不是通用行业标准，主要看 AKKO 自家模具
- **圆柱形**（Cherry / OEM）：前后方向有弧度、左右基本是直的，更贴合手指自然落点，现代键盘主流
- **平面**（XDA）：顶面接近平，面积最大，手指滑动最自由

Profile 只是大类，不是统一尺寸标准。可以把它理解成“鞋型”，厂商自己的模具像“鞋楦”：同样叫 Cherry、SA、XDA，不同厂商也可能顶面偏大/偏小、凹陷偏深/偏浅、边缘圆角偏圆/偏利。选购时更准确的问法是“这个品牌的这个 Profile / 这个系列是什么手感”，而不是只问“这个品牌顶面大不大”。

**生产工艺（字符怎么印上去的）：**

| 工艺 | 原理 | 耐用度 |
|------|------|--------|
| **二色成型** (Double-shot) | 两层塑料注塑，字符本身是另一块塑料 | 字符基本不会磨掉，顶级 |
| **热升华** (Dye-sub) | 高温把油墨"渗"进 PBT 塑料内部 | 非常耐磨，PBT 常用 |
| **镭雕/激光** (Laser) | 激光烧掉表面，露出底色或烧焦 | 一般，久了可能变浅 |
| **喷油+镭雕** | 喷层漆再刻字，喷漆会掉 | 最差，便宜键盘常用 |

> 无刻字键帽没有这些问题，因为没有字符。

**其他常见术语：**

| 术语 | 意思 |
|------|------|
| **ANSI** | 美国标准配列，回车是横向长条形；你的 Q3/Q6 是这个大类 |
| **ISO** | 欧洲标准，回车是倒 7 字形，左 Shift 也短一截 |
| **1u / 2u / 6.25u** | 键帽宽度单位，1u = 一个标准字母键宽度。空格通常是 6.25u |
| **104键 / 108键 / 87键** | 104/108 = 全尺寸（含数字键盘，Q6 属于这一类但具体键数看版本）；87 = TKL（无数字区，你的 Q3）|
| **增补键 (Extra/Mod kit)** | 额外的小包键帽，包含非标准尺寸（如 7u 空格、ISO 回车）|
| **打油** | ABS 材质长期使用后表面被磨光滑、发亮的丑态 |
| **GMK** | 德国键帽厂商，最有名的是 Cherry 高度二色 ABS 键帽；贵主要贵在设计、授权、做工、品牌和收藏属性 |
