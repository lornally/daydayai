| **🧪 好奇尝鲜** | **BOX 水母段落轴** | 操作力 **~50gf** | 透明壳颜值轴 |

**参数对比速查**：

```
操作力：云豹 45gf < 知夏/知秋/碎碎冰/午夜翡翠/极地狐 ~50gf < Navy 60g+
段落峰值：云豹 55gf ≈ 知秋 55gf < 碎碎冰 60gf ≈ 知夏/极地狐 ~60gf < 午夜翡翠 85gf
起始力：云豹 37gf < 其他 ~45-50gf
```

> 白轴 V2 和 Navy 各有维度但不在核心六件套。

### 关键发现

1. **操作力高度集中**：除云豹（45gf）和 Navy（60g+）外，知夏/知秋/碎碎冰/午夜翡翠/极地狐/夜萤/白枭/冰海精灵/粉紫/珠光紫/水母 操作力都在 **~50gf**。差异主要在段落峰值和结构上，不是触发压力。
2. **云豹真相**：起始力37gf确实最轻，但操作力仍是45gf（和白轴V2同级），真正卖点是 **CLICK声最大**。
3. **午夜翡翠真相**：触发50gf不算重，但段落峰值85gf是凯华Clicky家族最高，段落感最顶手。
4. **知秋双段弹簧**：操作力50gf/触感力55gf，双段让段落曲线更陡峭，"啪一下"更干脆。
5. **碎碎冰全POM**：操作力50gf/触感力60gf，全POM自润滑+Clicky的稀有组合。

## 五、购买提示

- **价格区间**：凯华 Clicky 轴基本都在 **¥1–3/颗**，放心买。
- **闭眼买**：BOX 白轴V2（最经典）、BOX 知夏（青轴终极升级）、极地狐（键圈热门高音脆亮）。
- **值得尝鲜**：知秋（双段弹簧）、云豹（最轻起始力）、碎碎冰（全POM顺滑）。
- **不买**：所有茶轴/提前段落/线性轴（和你需求相反）；午夜翡翠（段落峰值85gf太重太响，非日常用）；颜值轴（粉紫/珠光紫/水母段落）除非为了好看。
- **试轴建议**：先买 **"知系列混搭装"**（知春+知夏+知秋+知冬各3颗共12颗）+ **云豹轴10颗**，低成本试遍主要手感。
- **渠道**：认准淘宝/天猫官方旗舰店（Kailh旗舰店、Chosfox官方店），散装可混买。京东价格可能略高，但正品保障好。
- **兼容性**：凯华 BOX 系列、TTC 系列、佳达隆标准系列均为五脚轴，兼容热插拔键盘（如 Q3）。
