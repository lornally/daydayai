> macos的快捷键键位follow了emacs基础?

### f键

| 键   | macos系统                                  | 软件功能           | macos替代        | 典型场景                          |
| ---- | ------------------------------------------ | ------------------ | ---------------- | --------------------------------- |
| F1   | 亮度减                                     | 帮助文档           |                  | 几乎所有 IDE、终端、编辑器        |
| F2   | 亮度加                                     | 重命名             | Enter(Finder)    | VS Code、Finder、资源管理器       |
| F3   | Mission Control（多桌面视图）              | 查找下一个         | Cmd+G            | 浏览器、编辑器搜索                |
| F4   | Launchpad（应用启动器）                    | 地址栏/锁定引用    | Cmd+L(浏览器)    | 浏览器（地址栏），Excel（$锁定）  |
| F5   | 键盘背光减（MacBook）/ 听写（台式机）      | **运行/刷新**      | Cmd+R(刷新)      | **IDE 运行、浏览器刷新**          |
| F6   | 键盘背光加（MacBook）/ 勿扰模式（台式机） | 切换面板           |                  | VS Code、Chrome DevTools          |
| F7   | 上一曲                                     | 拼写检查/调试下一步 |                  | Word、部分 IDE                    |
| F8   | 播放/暂停                                  | 调试单步跳过       |                  | 大部分 IDE/调试器                 |
| F9   | 下一曲                                     | **断点开关**       |                  | VS Code、PyCharm、IntelliJ        |
| F10  | 静音                                       | 调试Step Over      |                  | 调试器                            |
| F11  | 音量减                                     | 调试Step Into/全屏 | Ctrl+Cmd+F(全屏) | 调试器、浏览器全屏                |
| F12  | 音量加                                     | **跳转到定义**     |                  | **VS Code、Chrome DevTools**      |

### 无用键

108键盘上存在但macOS上无用或行为不同的键：

| 键            | 原本含义（Windows/DOS）              | macOS上的情况                    |
| ------------- | ------------------------------------ | -------------------------------- |
| Print Screen  | 截屏                                 | 无效，用Cmd+Shift+3/4           |
| Scroll Lock   | 方向键从移动光标变为滚动页面（仅Excel还用）| 无效                          |
| Pause/Break   | 暂停程序执行/中断命令                | 无效                             |
| Insert        | 切换插入/覆盖输入模式                | 无效                             |
| Num Lock      | 切换小键盘数字/方向功能              | 无效，小键盘永远是数字           |
| Menu键(≡)     | 右键菜单（右Ctrl旁边）              | 无效                             |
| Home          | 跳到行首                             | 跳到文档开头（不是行首，Cmd+←才是行首）|
| End           | 跳到行尾                             | 跳到文档末尾（不是行尾，Cmd+→才是行尾）|
| Context Menu  | 部分键盘Fn旁的菜单键                 | 无效                             |
