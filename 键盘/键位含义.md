| 键   | macos含义功能                             | 一般软件含义 |
| ---- | ----------------------------------------- | ------------ |
| F1   | 亮度减                                    |              |
| F2   | 亮度加                                    |              |
| F3   | Mission Control（多桌面视图）             |              |
| F4   | Launchpad（应用启动器）                   |              |
| F5   | 键盘背光减（MacBook）/ 听写（台式机）     |              |
| F6   | 键盘背光加（MacBook）/ 勿扰模式（台式机） |              |
| F7   | 上一曲                                    |              |
| F8   | 播放/暂停                                 |              |
| F9   | 下一曲                                    |              |
| F10  | 静音                                      |              |
| F11  | 音量减                                    |              |
| F12  | 音量加                                    |              |

|             | 原本含义            | mac含义   |
| ----------- | ------------------- | --------- |
| num         | 小键盘作为数字/方向 | 不支持    |
| scroll lock |                     | 不支持    |
| insert      | 插入替换模式        | 不支持    |
| 截屏        |                     | cmd+3/4   |
| spotlight   |                     | cmd +空格 |
