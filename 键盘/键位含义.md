### 缘起

1. macos的快捷键键位follow了emacs体系
2. macos因为创始人jeff raskin的理念, 所以几乎不支持所有模态mode, 因此各种模态按键基本都失效了

| ---- | ------------------------------------------ | ------------------- | ---------------- | --------------------------------- |

| F6   | 键盘背光加（MacBook）/ 勿扰模式（台式机） | 切换面板            |                  | VS Code、Chrome DevTools          |

### 无用键

108键盘上存在但macOS上无用或行为不同的键：

| 键            | 原本含义（Windows/DOS）              | macOS上的情况                    |
| ------------- | ------------------------------------ | -------------------------------- |
| Print Screen  | 截屏                                 | 无效，用Cmd+Shift+3/4           |
| Scroll Lock   | 方向键从移动光标变为滚动页面（仅Excel还用）| 无效                          |
| Pause/Break   | 暂停程序执行/中断命令                | 无效                             |
| Insert        | 切换插入/覆盖输入模式                | 无效                             |
| Num Lock      | 切换小键盘数字/方向功能              | 无效，小键盘永远是数字           |
| Menu键(≡)     | 右键菜单（右Ctrl旁边）              | 无效                             |
| Context Menu  | 部分键盘Fn旁的菜单键                 | 无效                             |



### 6键区

| 按键     | 含义          | macos含义                               |
| -------- | ------------- | --------------------------------------- |
| ins      | 插入/覆盖模式 | 无用                                    |
| del      | 向后删除      | 生效                                    |
| Home     | 跳到行首      | 跳到文档开头（不是行首，Cmd+←才是行首） |
| End      | 跳到行尾      | 跳到文档末尾（不是行尾，Cmd+→才是行尾） |
| pageup   | 上一页        | 生效                                    |
| pagedown | 下一页        | 生效                                    |

### 无用键的替换目标

| 原始按键 | 原始键位置/含义    | 理由                 | 新含义            |
| -------- | ------------------ | -------------------- | ----------------- |
| 1号 截屏 | 6键顶部            | 更简洁的快捷键cmd3/4 | f5                |
| 2号 暂停 | 6键顶部            | 更简洁的空格         | 锁屏              |
| 3号 滚动 | 6键顶部            | 无用模态             | f12               |
|          |                    |                      |                   |
| ins      | 6键区              | 无用模态             | rgb灯光模式-      |
|          |                    |                      |                   |
| f11      | 音量减             | 旋钮替代             | 灯光sat饱和度减小 |
| f12      | 音量加             | 旋钮替代             | 灯光饱和度增加    |
| f13      | 小键盘数字区顶部   | 无用                 | hue色相+0         |
| f14      |                    | 无用                 | 灯光速度降低      |
| f15      |                    | 无用                 | 灯光速度增加      |
| f16      | z6没有, q6有       | 无用                 | rgb灯光模式+      |
| num      | 小键盘数字区左上角 | 无用模态             | hue色相-          |
