| 键   | macos系统                         | 软件功能                  | 典型场景                    |
| ---- | ----------------------------------------- | ----------------------------------------- | ----------------------------------------- |
| F1   | 亮度减                                    | 帮助文档                        | 几乎所有 IDE、终端、编辑器             |
| F2   | 亮度加                                    | 重命名   | VS Code、Finder、资源管理器 |
| F3   | Mission Control（多桌面视图）             | 查找下一个                      | 浏览器、编辑器搜索                  |
| F4   | Launchpad（应用启动器）                   | 跳转到定义/地址栏 | 浏览器（地址栏），Excel（锁定引用） |
| F5   | 键盘背光减（MacBook）/ 听写（台式机）     | **运行/刷新** | **IDE 运行、浏览器刷新** |
| F6   | 键盘背光加（MacBook）/ 勿扰模式（台式机） | 切换面板    | VS Code、Chrome DevTools |
| F7   | 上一曲                                    | 拼写检查/调试下一步      | Word、部分 IDE     |
| F8   | 播放/暂停                                 | 调试单步跳过    | 大部分 IDE/调试器 |
| F9   | 下一曲                                    | 断点开关                     | VS Code、PyCharm、IntelliJ |
| F10  | 静音                                      | 单步进入      | 调试器       |
| F11  | 音量减                                    | 单步进入/全屏        | 调试器、浏览器全屏      |
| F12  | 音量加                                    | **跳转到定义**   | **VS Code、Chrome DevTools** |





macos无用键位:

|             | 原本含义            | mac含义   |
| ----------- | ------------------- | --------- |
| num         | 小键盘作为数字/方向 | 不支持    |
| scroll lock |                     | 不支持    |
| insert      | 插入替换模式        | 不支持    |
| 截屏        |                     | cmd+3/4   |
| spotlight   |                     | cmd +空格 |
|             |                     |           |
|             |                     |           |
|             |                     |           |
