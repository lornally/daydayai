摩托车没有唯一分类标准，通常按骑行用途和外形分为这些主要品类：

- 街车（Naked）：通勤、日常和玩乐兼顾，坐姿较直立。例：本田 CB650R、雅马哈 MT-07。
- 仿赛／跑车（Sport）：有整流罩，低趴坐姿，强调操控和速度。例：川崎 ZX-6R、宝马 S1000RR。
- 巡航（Cruiser）：座高低、轴距长、坐姿舒展，强调低转扭矩和风格。例：哈雷、印第安、本田 CM500。
- 旅行车（Touring）：强调长途舒适性、风挡、边箱和载人能力。例：宝马 R1250RT、本田金翼。
- ADV／探险车：
  - 兼顾公路长途和轻度非铺装路面，坐姿高、减震行程长。例：宝马 GS、本田 Africa Twin。
- 拉力车（Rally）：
  - 更偏越野和长距离穿越，可看作更硬核、更轻量的 ADV。例：KTM 450 Rally。
- 越野车（Dirt Bike）：
  - 主要跑泥地、林道和赛道，轻量、长行程减震，部分车型不能合法上公路。
- 滑胎车（Supermoto）：
  - 越野车车架配公路轮胎，适合铺装路面的急弯和玩乐。
- 复古车（Retro／Classic）：以经典外观为主，下面还能细分 Cafe Racer、Scrambler、Bobber 等。
- 踏板车（Scooter）：自动挡、坐姿轻松、储物方便，适合城市通勤。例：本田 PCX、雅马哈 TMAX。
- 弯梁车（Underbone）：车架低、轻便省油，多为小排量。例：本田幼兽。
- 迷你车／玩乐车（Mini Bike）：尺寸小，偏城市代步和娱乐。例：本田 Monkey、MSX125。

- 油箱+塑料件贴膜 = 亮光金属绿
- 坐垫重包 = 皮质绿

这两个绿**很难完全一致**,因为材质不同(金属漆反光 vs 皮料哑光)。所以聪明的做法有两种:

- **同色系不同深浅**:坐垫用比车身**更深或更浅**的绿,反而好看(双色层次感)
- **坐垫用撞色**:绿色车身 + 黑色坐垫,经典运动风,零色差烦恼

## 浅草绿车身,坐垫的"设计级"选择

**1. 奶油白/米白(不是纯白)**

- 纯白太刺眼,和浅草绿会"打架";**奶油白**带一点点暖黄调,和浅草绿是同族色系(都偏黄),柔和、复古、高级
- 视觉上像"春天的奶油抹茶",比纯白耐看很多
- ⭐ 如果你要白,这是白里的正确选择

**2. 浅驼/奶茶棕**

- 浅草绿(冷中带黄)+ 浅驼色(暖大地色),是"自然系"配色——草色+土地色
- 复古味浓,越看越耐,还不显脏
- 这是很多人没想到但实际很出彩的选择

**3. 墨绿(比车身深一档的绿)**

- 车身浅草绿 + 坐垫深绿,**同色系深浅分层**——最高级的配色手法之一
- 不撞色,靠"色差"制造层次,低调但很有质感
- ⭐ 想耐看低调就选它

**4. 焦糖棕(深一点)**

- 绿 + 深棕,像"苔藓+树皮",硬朗复古
- 比浅驼更稳更man,适合想要一点硬朗感的

**5. 橙色**(前面提过,依旧成立)

- 活泼、出彩、活力担当

## 做个排除法帮你收窄

| 你的偏好     | 选               |
| ------------ | ---------------- |
| 要"干净清爽" | 奶油白           |
| 要"复古耐看" | 浅驼 / 焦糖棕    |
| 要"高级低调" | 墨绿(同色系分层) |
| 要"活泼出彩" | 橙色             |

**我的最终推荐前两名:**

1. **奶油白**——你原本就想白,但换成奶油白更配浅草绿,完美解
2. **墨绿**——同色系分层是设计师手法,低调耐看还不容易看腻

坦白说,浅草绿这种"黄调绿"配**暖色系**(奶油白/驼色/橙)都成立,配冷色(蓝、纯白、银)都不够好。所以核心逻辑是:**往暖色选,别往冷色选**。
