### 9.16
qbittorrent能否改变下载内容? 就是一个torrent中其实我不需要下载那些广告内容.

可以, BT 本身就支持文件级选择下载:
- 添加时: 选项 → 行为 → 打开"添加 torrent 时显示内容选择对话框", 弹窗里取消勾选广告文件。磁力链要先等元数据取回来(内容标签页出现文件列表)才能选。
- 已添加的: 选中种子 → 下方"内容"标签 → 右键文件 → 优先级 → 不下载。已下完的文件改成"不下载"会被自动删掉, 没删就先暂停种子再改。

限制: BT 的下载/校验单元是 piece(分块, 通常 1~4MB)而不是文件。
- 广告文件独占一个 piece → 能完全不下载
- 广告文件跟正片共享一个 piece → 那块数据照下, 磁盘上残留 .!qB 碎片(几十KB~几MB)

所以跳过 xxx.url / 宣传.txt / sample 这类小文件可行, 但省不了多少体积, 主要是目录干净。
压进视频里的广告跟 BT 无关, 只能下完用 ffmpeg 剪。


* 剪片子, 用ffmpeg吗?

是, ffmpeg 已装好(/opt/homebrew/bin/ffmpeg)。剪广告用无损流复制, 不重新编码, 秒完成:
  ffmpeg -ss 00:01:30 -i in.mkv -t 00:43:30 -c copy -map 0 out.mkv
  -ss 放 -i 前面=快速定位(关键帧级); -t 是保留时长; -map 0 保留所有音轨字幕; 输出用 .mkv 容器最保险
代价: 只能在关键帧切, 切点会差几秒; 开头黑屏花屏就加 -avoid_negative_ts make_zero
要精确切点才需要重编码(慢+轻微有损): -c:v libx264 -crf 18 -preset slow -c:a copy

更省事: LosslessCut —— 图形界面, 底层就是 ffmpeg, 拖时间轴框选片段导出, 可剪掉中间的多段广告再拼
  brew install --cask losslesscut   (下载挂 clash: export https_proxy=http://127.0.0.1:7890)

硬压进画面里的水印/滚动广告剪不掉, 只能 crop 或换片源。

* losslesscut做剪切的时候, 能否顺手帮忙把视频压缩了?
* 或者说macos上面有没有比较好的批量的视频压缩工具?

答:
LosslessCut 不能压缩 —— 它的整个设计就是"无损", 剪切走的是 `-c copy` 直接复制码流, 不重新编码, 所以画质和体积都不变。
  唯一沾边的是 Smart cut: 只对"切点所在的这一段 GOP"重编码, 目的是让切点不卡关键帧; 而且它是按原码率 x1.2 编的, 文件不会变小。
  想"剪 + 压"一步到位, 用 ffmpeg 一条命令 (本机已装 ffmpeg 8.1):

```sh
# 剪切 + 重编码压缩 (输入时间轴 12:30 ~ 45:00)
ffmpeg -ss 00:12:30 -to 00:45:00 -i in.mp4 \
  -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k \
  -movflags +faststart out.mp4

# 想快就用 Apple 硬件编码 (M 系列芯片快很多, 同画质体积略大)
ffmpeg -ss 00:12:30 -to 00:45:00 -i in.mp4 \
  -c:v hevc_videotoolbox -q:v 60 -tag:v hvc1 -c:a aac -b:a 128k \
  -movflags +faststart out.mp4
```

crf 越低越清晰也越大, 常用 20~23 (23 是默认, 肉眼看不出差别), 体积一般能砍到 30%~50%。重编码有代际损失, 同一部片别反复压。

macOS 批量压缩工具:
* HandBrake —— 免费开源, 首选。一堆文件拖进去 → Add to Queue → Start Queue 就是批量; 预设挑 Apple VideoToolbox 系列能吃硬件加速。 `brew install --cask handbrake` (下载挂 clash: export https_proxy=http://127.0.0.1:7890)
* Shutter Encoder —— 免费, 同样是 ffmpeg 套壳, 批量和参数比 HandBrake 更细。
* Permute —— 付费, 拖拽即转, 最省事但可控性弱。
* ffmpeg 自己写循环, 最灵活:

```sh
mkdir -p out
for f in *.mp4; do
  ffmpeg -i "$f" -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k -movflags +faststart "out/${f%.*}.mp4"
done
```

推荐流程: 先用 LosslessCut 无损剪掉广告/头尾 (秒级完成、不掉画质), 再拿 HandBrake 或上面的循环批量压 —— 还是两件事分开做, 别指望一个工具全包。
