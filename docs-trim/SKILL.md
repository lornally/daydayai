# Docs Trim

只改文档。不要改代码。

## Rules

1. 单点维护。
2. 简洁优先。
3. 文档禁代码，除非用户明确要。
4. 用案例讲，不讲理论。
5. 删重复。

## Shape

保留：

- 做什么。
- 何时做。
- 一个案例。
- 验收方式。

删除：

- 背景。
- 动机长文。
- 重复规则。
- 泛泛最佳实践。
- 长案例。

## Stop

实现细节若该进代码注释或测试，删。

案例不能证明规则，就换或删。
