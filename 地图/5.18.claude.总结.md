# 世界地图项目技术总结

## 项目目标

生成一张**以中国为正中心**（x+y 双方向）的世界地形图，要求：
- 完整地球，不裁剪
- 有地形立体感（山脉浮雕、海洋深度）
- 区分地表类型（森林、草原、沙漠、雪山）
- 适合 A1/A0 大幅打印（300dpi）
- 可旋转（东在上/西在上）

---

## 核心技术难题与解法

### 难题：标准投影无法让中国居中

Robinson、EqualEarth 等伪圆柱投影的赤道是固定的。设置中心经线 103°E 只能实现水平居中，纵向上中国永远偏北（赤道在图中心）。

### 解法：球面坐标旋转（Oblique Transformation）

不改投影，改数据。把地球坐标系旋转，让目标点（103°E, 35°N）变成新坐标系的 (0°, 0°)，再用标准投影渲染。

数学本质：欧拉角旋转（绕 Y 轴旋转纬度 → 绕 Z 轴旋转经度），等价于天文学中的坐标系变换。

## 关键技术手段详解

### 1. 球面坐标旋转

**为了**：让任意经纬度点成为地图正中心
**做法**：
```
原始 (lon, lat) → 笛卡尔 (x, y, z) → 绕Y轴旋转center_lat → 绕Z轴旋转center_lon → 新 (lon', lat')
```
对栅格数据：生成输出网格 → 逆旋转找原始坐标 → `scipy.ndimage.map_coordinates` 双线性插值采样
对矢量数据：逐顶点正向旋转 → 在 ±180° 经线处断开（`split_line_at_dateline`）

### 2. Hillshade（山体阴影）

**为了**：让山脉有立体浮雕感
**做法**：从 DEM 计算梯度（`np.gradient`），模拟方向光源（方位角 315°，高度角 45°），得到每个像素的明暗值，与颜色相乘。

### 3. 高程分层设色 + 地表类型混合

**为了**：区分沙漠/森林/草原/高山，同时保留高程信息
**做法**：
- 低海拔（<2000m）：用 Natural Earth 2 的真实卫星颜色（自带地表类型信息）
- 高海拔（>2000m）：渐变覆盖为高原棕→高山灰→雪白
- 颜色增强：检测绿色像素的亮度/饱和度，分类为森林（墨绿）或草原（浅黄绿）

### 4. 海洋处理

**为了**：海洋统一深蓝到黑，不干扰陆地观感
**做法**：
- v3 kimi：颜色阈值法检测海洋像素（B > G+0.05 且 B > R+0.05），替换为统一深蓝
- v4-v7 claude：直接用 DEM < 0 判断海洋，按深度映射颜色（深海→黑，浅海→深蓝）

### 5. Bearing 旋转（视线轴旋转）

**为了**：生成"东在上"或"西在上"的地图（保持椭圆形状不变）
**做法**：在球面旋转后，额外绕 X 轴（视线轴）旋转 ±90°，中心点不动，周围内容绕中心旋转。

### 6. 高分辨率直出（v7）

**为了**：突破 matplotlib 的分辨率限制，输出 50000×25000 像素
**做法**：
- 用 `pyproj` 做投影逆变换（从像素坐标→经纬度）
- 分块处理（每块 500 行），避免内存爆炸
- 用 PIL 直接保存 RGB 数组为 PNG

## 两条技术路线对比（kimi 探索）

| 路线 | 思路 | 数据 | 优劣 |
|------|------|------|------|
| 路线 A | 从 ASTER GDEM Color Index 的颜色反推高程 → 自算 hillshade → 自定义 colormap | ASTER GDEM Color Index (PNG) | 可控性强，但颜色→高程的反推精度有限 |
| 路线 B | MODIS Land Cover 提供地表分类 + ASTER GDEM Greyscale 提供明暗 → 按分类着色 × 明暗调制 | MODIS Land Cover + ASTER Greyscale | 地表类型准确，但需要精确的颜色匹配阈值 |

## 技术栈

| 库 | 用途 |
|----|------|
| Python 3.12 | 运行时 |
| Cartopy | 地图投影、网格线、矢量要素 |
| Matplotlib | 渲染输出（v1-v6） |
| NumPy | 数组运算、颜色映射、hillshade 计算 |
| SciPy | `map_coordinates` 球面重采样、`gaussian_filter` 平滑 |
| Shapely | 矢量几何旋转、经线分割 |
| Pillow (PIL) | 图像 I/O、高分辨率直出（v7） |
| netCDF4 | 读取 ETOPO DEM 数据（.nc 格式） |
| PyProj | 坐标转换、投影逆变换（v7） |
| Rasterio | GeoTIFF 处理（预留） |

## 未来方向

1. **真实土地覆盖**：ESA WorldCover / MODIS Land Cover 替代颜色推断
2. **更高精度 DEM**：ETOPO 15弧秒版 (86400×43200) 或局部 SRTM 30m
3. **3D 渲染**：aerialod / Blender GIS 做真正的 3D 透视效果
4. **多源融合**：DEM + Land Cover + 卫星影像 + 水系矢量
5. **打印优化**：针对哑光/光面纸张调整色彩空间
