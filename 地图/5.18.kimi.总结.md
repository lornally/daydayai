# 中国中心世界地图 — 技术总结（截至 2026.5.18）

> 本文档总结"以中国为中心的世界地形图"项目从需求到落地的完整技术路线，按**因果链**组织：为了达成什么目标 → 遇到什么问题 → 采用什么数据 / 什么技术手段 → 结果如何 → 下一个目标。

---

## 一、原始需求与核心矛盾

### 1.1 需求
- **中国位于世界地图正中心**（x + y 双方向，不只是经度居中）
- **有地形**（3D 浮雕感、高程分层设色）
- **完整地球**（不能是半个地球的裁剪）
- **适合大幅打印**（A1/A0，300dpi）

### 1.2 核心矛盾
标准伪圆柱投影（Robinson、EqualEarth、Mollweide）的**赤道和中央经线是固定的**：
- 把中央经线设为 103°E → 中国在 **x 方向**居中（左右居中）✅
- 但赤道仍在图片正中间 → 中国（35°N）在 **y 方向**偏上 ❌

数学上不存在"支持任意纬度作为新赤道的标准伪圆柱投影"。

### v3：斜轴旋转突破（核心创新）

| 项目 | 内容 |
|------|------|
| **目标** | 在保持完整地球的前提下，实现 x + y 双方向真正居中 |
| **核心思想** | 不寻找"支持偏心纬度的投影"（数学上不存在），而是**旋转数据**：把地球转一下，让中国对准新坐标系的 (0°, 0°)，再套标准投影 |
| **数学原理** | 球面坐标旋转（Oblique Transformation，等价于天文学的黄道→赤道坐标转换）：<br>1. 绕 Z 轴旋转 `-center_lon` → 经度归零<br>2. 绕 Y 轴旋转 `center_lat` → 纬度归零（目标点移到新赤道）<br>3. 绕 Z 轴旋转 180° → 中国面向观察者 |
| **数据升级** | **ASTER GDEM Color Shaded Relief**（NASA GIBS WMS，10800×5400，~2km/px）— 预渲染的 DEM 高程分层设色 + 山体阴影 |
| **矢量数据** | Natural Earth 1:110m（海岸线、国界、河流）— 逐顶点旋转后叠加 |
| **关键技术** | `scipy.ndimage.map_coordinates` 双线性插值球面重采样；shapely 几何旋转；±180° 日期变更线分割处理 |
| **结果** | 12 张图（2 中心点 × 3 投影 × 2 风格），中国真正位于正中心 |
| **遗留问题** | `shaded_relief` 风格下，cartopy 动态矢量图层（OCEAN/LAND）与旋转后的 raster 底图**空间错位**；ASTER GDEM 是预渲染 JPG，颜色已 baked，**无法自定义**分层设色 |

---

### v4：错位修复 + 海洋压制（kimi 版本）/ ETOPO DEM 自渲染（claude 版本）

两条路线并行解决 v3 的遗留问题：

#### 路线 A — kimi v4：修复错位
| 项目 | 内容 |
|------|------|
| **目标** | 消除 shaded_relief 风格下矢量图层与 raster 底图的空间错位 |
| **根因** | cartopy `cfeature.OCEAN` 是独立矢量图层，坐标未经过与底图一致的球面旋转 |
| **技术** | 放弃 cartopy 动态 ocean feature，改用**颜色阈值法**直接替换 ASTER GDEM 中的海洋像素：`(B > G + 0.05) & (B > R + 0.05) & (R < 0.45)` → 替换为深蓝 `#1A3B5C` |
| **结果** | 矢量与 raster 完全一致，无错位、无边缘 artifact；8 张图（去掉 Mollweide 和 minimal） |

#### 路线 B — claude v4：突破预渲染限制
| 项目 | 内容 |
|------|------|
| **目标** | 摆脱 ASTER GDEM 预渲染图的束缚，实现完全自定义的颜色映射 |
| **数据** | **ETOPO 2022 全球 DEM**（NetCDF，21600×10800，1 弧分分辨率，高程范围 -10752m ~ 8157m） |
| **技术** | 从 DEM 直接计算颜色，三种风格：<br>• `relief_dark`：非线性灰度映射（深海黑 → 平原深灰 `#333` → 高山白）<br>• `hypsometric`：自定义高程色带（海洋深蓝→黑，陆地绿→棕→白）<br>• `relief_ocean`：陆地灰度浮雕 + 海洋蓝色深度 |
| **关键修复** | DEM 纬度方向 bug（南极在 row 0，需用 `orig_lat + 90` 而非 `90 - orig_lat`） |
| **结果** | 12 张图，颜色完全可控；但陆地只有高程色带，**缺乏地表类型区分**（沙漠/草原/森林），立体感仍不足 |

---

### v5：Hillshade + 地表类型着色（claude 版本）

| 项目 | 内容 |
|------|------|
| **目标** | 增加山脉立体感；区分地表类型（沙漠/草原/森林/高原/高山/雪山） |
| **数据** | ETOPO 2022 DEM + **Natural Earth 2（NE2，50m 版本）**真实地表颜色 |
| **技术** | 1. 从 DEM 计算 **hillshade**（光源方位角 315°、高度角 45°，`numpy.gradient` 求坡度坡向）<br>2. 低海拔（<2000m）用 NE2 真实地表颜色（森林绿、沙漠黄、草原浅绿）<br>3. 高海拔（2000m+）用 DEM 高程色带渐变覆盖（高原棕 → 高山灰 → 雪山白）<br>4. `land_color × hillshade` 叠加立体感 |
| **结果** | 2 张精品图（北京-Robinson、中国-EqualEarth）；有立体感，但 NE2 分辨率有限，颜色区分不够鲜明 |

### v6：高分辨率 + 颜色增强 + 旋转版本（claude 版本）

| 项目 | 内容 |
|------|------|
| **目标** | 提升分辨率；增强森林/草原颜色区分；增加"东在上/西在上"旋转版本 |
| **数据升级** | Natural Earth 2 **高分辨率**（21600×10800）；ETOPO DEM 全分辨率 |

| **遗留问题** | 仍然通过 matplotlib 渲染，超高分辨率下内存和性能受限；用户反馈"模糊"、"旋转后中国不在中间"（bearing 旋转轴选择问题） |

### v7：高精度直出 + 修正旋转（claude 版本，当前最新）

| 项目 | 内容 |
|------|------|
| **目标** | 突破 matplotlib 分辨率天花板，直接输出 50000×25000 超高分辨率 |
| **技术突破** | **完全绕过 matplotlib**：<br>1. `pyproj` 直接做投影逆变换（Robinson/EqualEarth → WGS84）<br>2. `PIL.Image.fromarray` 直接输出 PNG<br>3. **分块处理**（每块 500 行），避免内存爆炸 |

| **结果** | 目标输出 50000×25000（约 1.25 Gigapixel），适合大幅打印 |

| 项目 | 内容 |
|------|------|

| 项目 | 内容 |

## 五、核心数学原理速查

### 1. 球面坐标旋转（让中国居中）
```
原始坐标 (lon, lat)
    ↓
绕 Z 轴旋转 -center_lon  → 经度归零
绕 Y 轴旋转 center_lat   → 纬度归零（目标点移到新赤道）
绕 Z 轴旋转 180°         → 中国面向观察者
    ↓
新坐标 (lon', lat') — 在新坐标系中做标准 Robinson/EqualEarth 投影
```

### 2. Hillshade（山体阴影）
```python
dy, dx = np.gradient(dem)
slope = arctan(sqrt(dx² + dy²))
aspect = arctan2(-dx, dy)
hillshade = sin(alt) * cos(slope) + cos(alt) * sin(slope) * cos(az - aspect)
```

### 3. 颜色合成公式
```python
最终颜色 = base_color × hillshade        # 陆地：地表颜色 × 光影
海洋颜色 = f(dem_depth)                  # 海洋：深度 → 深蓝到黑
```

- ✅ 完整地球、中国 x+y 双方向真正居中

### 待解决
- ⏳ **精度天花板**：当前全球 1 弧分（~1.8km）vs 甘肃底图参考的 30m SRTM，差距约 60 倍
- ⏳ **森林/草原颜色**：连续权重混合仍有改进空间，需更精确的土地覆盖数据（ESA WorldCover）
- ⏳ **水系/湖泊**：当前仅矢量线条，缺少大面积水体（里海、五大湖等）的精确填充
- ⏳ **打印色彩空间**：未针对打印介质（哑光/光面）做 CMYK 转换和色彩校准

### 未来技术路线
1. **短期**：接入 ESA WorldCover 土地覆盖数据，精确替换森林/草原/沙漠颜色
2. **中期**：ETOPO 2022 15 弧秒版本（86400×43200，4 倍精度）或局部 SRTM 30m 精修
3. **长期**：ArcGIS Pro / Aerialod / Blender GIS 专业 3D 渲染工作流
